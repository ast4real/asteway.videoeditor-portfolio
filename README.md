# Asteway Melese – Video Editor Portfolio
- Files: `index.html` (content), `style.css` (design), `script.js` (project list and video behavior)
- Put your photo at `assets/profile.jpg`
- Add videos to `assets/videos/` and list them in the `projects` array in `script.js`
- Videos over 100 MB can't go on GitHub: upload to YouTube/Drive and use an `<iframe>` instead.
